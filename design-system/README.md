# Design-system inputs

`interiorin/MASTER.md` is the persisted output of the project-required `ui-ux-pro --design-system` search. It is retained as reproducible design research, not treated as automatic visual authority.

Precedence for implementation:

1. Approved Forge design document under `docs/design/`.
2. Page-specific files under `design-system/interiorin/pages/`.
3. This generated master recommendation.
4. Component-library defaults.

The generated master correctly identifies the need for an interactive 3D configurator, explicit alternative content, responsive breakpoints, visible focus, reduced motion, and careful performance. Its generic e-commerce conversion framing, single-font recommendation, gold CTA, and hover-lift card treatment are provisional and must not override the `elite-frontend-design` anti-slop standard or the approved tactile editorial direction.

21st.dev components are source patterns, not drop-in visual decisions. Check accessibility, license, bundle impact, and token fit before adopting any component.
