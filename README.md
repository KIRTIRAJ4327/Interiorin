# Interiorin

Interiorin is a voice-refinable spatial design studio for real interior and exterior spaces.

The product is built around three truths:

1. **Spatial truth:** start from a photo, floor plan, or guided views; disclose what is measured, inferred, and unknown.
2. **Design intelligence:** create coherent options that respond to scale, circulation, light, context, maintenance, and user intent—not merely a style label.
3. **Decision memory:** every accepted refinement changes known scene data, can be saved as a named option, and can be compared before money or construction effort is committed.
