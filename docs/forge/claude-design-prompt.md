# Claude Design prompt — Interiorin

Design Interiorin as a complete, production-grade residential spatial decision studio for homeowners, renters, and distinct residential professionals. A person can show an empty or existing interior or exterior, build an honest source-aware baseline, receive materially different reasoned directions, refine them through keyboard, touch, text, direct manipulation, or bounded ElevenLabs voice, save immutable named versions, compare facts, attach labelled Gemini/Nano Banana presentation derivatives, and prepare a scoped professional handoff.

## Exactly three flows and 11 screens

### Flow 1 — real evidence to honest baseline

**F1.1 Project Folio.** Desktop eight-column form/four-column sticky source-limit ledger; mobile stacks. Fields: name, Interior/Exterior, Empty/Existing, decision intent, and evidence routes. Data is user input only. Default `Start with the space you have.` Loading `Creating your evidence mission…`. Duplicate error `“Cedar House kitchen” already exists. Open it or use a different name.` Offline `Files stay on this device until connection returns.` Dirty Cancel offers `Save draft and leave`, `Leave without saving`, `Stay`; Cancel returns to Projects and focuses `New project`.

**F1.2 Evidence Mission.** Desktop 280 px ordered task rail, center task, right source/privacy/coverage ledger; mobile ordered tasks above active task and sticky Review. Task states are not_started → active → uploading/processing → complete; optional skipped(reason); failures retry/replace/remove; Reopen marks dependencies needs_review. Interior IDs: I00 permissions/privacy, I10 frame, I20 boundaries, I30 openings, I40 retained objects, I50 scale anchor, I60 limits. Exterior: E00 permissions/privacy, E10 zone, E20 boundary, E30 grade/drainage, E40 utilities/structures, E50 setbacks/jurisdiction, E60 environment, E70 scale, E80 limits. Validate integer mm: walls 300–30,000, ceiling 1,800–10,000, openings 100–10,000 width/100–5,000 height, objects 10–10,000, anchors 10–30,000. Images ≤20 MB/40, videos ≤250 MB/5, PDFs ≤50 MB/10; reject MIME mismatch, zero-byte, protected, or failed malware check. Permission error `Camera blocked by browser. Allow access in site settings or continue with uploads/manual measurements.` Remove source confirms dependent facts become unresolved; replacement succeeds before old removal. Review enables only when all required tasks complete, one source exists, fit work has scale, nothing required is processing/error/needs_review, and I60/E80 is acknowledged.

**F1.3 Baseline Review.** Seven-column 3D/2D/Source stage plus five-column baseline/fact/object/gap rail; mobile facts/blockers first. Data is interpreted baseline linked to original sources, authority, freshness, and dependencies. Default `Review what the baseline knows—and what it does not.` Blocked `Cannot accept for “Fit a dining table”: room scale is unresolved.` Canvas error `The model could not render. Your facts, sources, and baseline controls are still available below.` Correcting an accepted baseline creates a correction draft/new version; discard leaves accepted state untouched.
